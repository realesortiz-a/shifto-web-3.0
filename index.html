Manual de SHIFT0

1. ¿Cómo usar la página?

  1. Para codificar, escribe un mensaje en el primer cuadro.
  2. Pulsa «Codificar» para generar el código.
  3. Pulsa «Copiar código» para copiar el resultado.
  4. Para descodificar, pega el código en el cuadro correspondiente.
  5. Pulsa «Descodificar» para recuperar el mensaje.
  6. Usa «Borrar» para vaciar el cuadro que quieras.

2. Regla de las letras mayúsculas

  1. Avanza una posición en el alfabeto.
  2. Busca la posición de la letra resultante.
  3. Suma 3 al número obtenido.
  4. Escribe el resultado con cuatro ceros delante.

Ejemplo: A pasa a B; B ocupa la posición 2; 2 + 3 = 5; el código es 00005.

3. Regla de las letras minúsculas

Se aplica el mismo desplazamiento y la misma suma, pero se representa el resultado con dos ceros delante y dos detrás.

Ejemplos definidos: 00500 y 00900. El formato todavía requiere una convención inequívoca para todos los números.

4. La Ñ

La Ñ es una letra independiente, situada después de la N y antes de la O.

5. Vocales acentuadas y Ü

  • Las vocales Á, É, Í, Ó y Ú usan el prefijo 6.
  • La Ü usa el prefijo especial 606.
  • Ejemplos definidos: Á → 600005; Ü → 606000022.

6. Símbolos

El formato es 80 + número asignado + 08.

  • ! = 1
  • " = 2
  • # = 3
  • $ = 4
  • % = 5
  • ? y ¿ = 6
  • / = 7
  • ( = 8
  • ) = 9
  • = = 0

Ejemplo: ! → 80108.

7. Números reales

Los dígitos se convierten directamente en letras: 0=A, 1=B, 2=C, 3=D, 4=E, 5=F, 6=G, 7=H, 8=I, 9=J.

Ejemplo: 2026 → CACG.

Hace falta una marca especial para distinguir esos números de las letras normales.

8. Espacios y puntuación

  • Los espacios se representan con |.
  • El punto, la coma y los dos puntos se conservan.

Importante: las reglas anteriores incluyen formatos pendientes de resolver. Esta página muestra el manual, pero el algoritmo completo debe validarse antes de considerarse compatible con todas las reglas de SHIFT0.
